# farmer-ai (KisanSathi)

Farmer-focused app: a farmer photographs a crop leaf, the app checks it and
shows simple advice in plain language. This is a prototype in progress.

## What lives here

- `app/` — Flutter Android app (comes after the go-ahead)
- `backend/` — FastAPI backend (comes after the go-ahead)
- `infra/` — Azure setup files (comes after the go-ahead)

## Status

Skeleton only: folder structure, this README and a `.gitignore`.
No app code, no backend code and no cloud resources yet.

## Rules

- Never commit secrets, keys, passwords or tokens into this repo.
  Secrets live in Azure Key Vault or GitHub secrets, never in code.
- A coding-standards file (`AGENTS.md`) will be added with the foundation
  step, after the go-ahead.
